# Design Patterns Mastery Journal

Welcome to my design patterns learning repository! This project contains my implementations of standard Gang of Four (GoF) design patterns in both **Java** and **Ruby** to learn their structures, trade-offs, and behavioral characteristics across static and dynamic language paradigms.

## Repository Structure

```
design_patterns/
├── README.md                  # This file
├── creational/                # Creational patterns
├── structural/                # Structural patterns
├── behavioral/                # Behavioral patterns
└── additional/                # Additional / Less common GoF patterns
```

Each pattern contains:
- `PROBLEM.md`: Problem description, class diagram, and Java vs. Ruby reflections.
- `java/`: Runnable Java implementation.
- `ruby/`: Runnable Ruby implementation.
